> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship five bespoke featured project pages (LilSeeGround, Adaptive MAPPO, Horizon, HRMS, Battery PGML) plus a featured section on `/projects`, and deploy to production.

**Architecture:** `data/projects.js` gains `featured: true` entries; `app/projects/[slug]/page.js` renders `components/projects/<slug>/Page.jsx` for featured slugs and the existing template otherwise. Pages compose shared blocks (`components/projects/blocks/`) and hand-written SVG charts (`components/projects/charts/`), with data JSON extracted by Node scripts from the source repos so every plotted value is real (or an explicit placeholder).

**Tech Stack:** Next.js 16 App Router, React 19, framer-motion 12, CSS Modules, Node 25 (`node --test` for scripts and pure helpers), ffmpeg (video), pdftoppm + macOS `sips` (images).

**Spec:** `docs/superpowers/specs/2026-10-11-featured-projects-design.md`

```js
export const linearScale = ([d0, d1], [r0, r1]) => (x) => r0 + ((x - d0) / (d1 - d0)) * (r1 - r0);
export const logScale = ([d0, d1], [r0, r1]) => { const l0 = Math.log10(d0), l1 = Math.log10(d1); return (x) => r0 + ((Math.log10(x) - l0) / (l1 - l0)) * (r1 - r0); };
export function niceTicks(min, max, count = 5) {
  const raw = (max - min) / count, mag = 10 ** Math.floor(Math.log10(raw)), n = raw / mag;
  const step = (n <= 1 ? 1 : n <= 2 ? 2 : n <= 5 ? 5 : 10) * mag;
  const out = [];
  for (let v = Math.floor(min / step) * step; v <= Math.ceil(max / step) * step + 1e-9; v += step) out.push(+v.toFixed(10));
  return out;
}
```
